# GameHub - 小游戏集合平台

一个现代化、响应式的小游戏集合平台，提供丰富多样的休闲娱乐体验。

## 🎮 游戏列表

GameHub 包含以下经典小游戏：

- **新记忆配对游戏** - 多种难度、主题切换、提示功能、最高分记录
- **新贪吃蛇游戏** - 多种食物类型、道具系统、粒子特效、最高分记录
- **新打砖块游戏** - 道具系统、连击机制、多关卡挑战、粒子特效
- **2048数字游戏** - 方块移动合并、分数计算、撤销功能、自动演示
- **俄罗斯方块游戏** - 方块控制、消除得分、等级提升、最高分记录
- **太空射击游戏** - 飞船控制、射击系统、敌人系统、道具系统、粒子特效
- **连连看游戏** - 三种难度、路径查找、提示功能、重排功能、最高分记录
- **扫雷游戏** - 三种难度、地雷生成、自动展开、计时器、最高分记录
- **数独游戏** - 三种难度、回溯算法生成、数字填入、检查提示、最高分记录
- **五子棋游戏** - 15x15棋盘、黑白轮流落子、五连珠检测、悔棋功能、胜场记录

## 🚀 快速开始

### 直接访问

直接在浏览器中打开 `index.html` 文件即可体验或者访问https://wwsta.github.io/GameHub

### 本地服务器

使用任何静态网站服务器运行项目，例如：

使用 Python：
```bash
python -m http.server 8000
```

使用 Node.js (http-server)：
```bash
npx http-server -p 8000
```

使用 PHP：
```bash
php -S localhost:8000
```

然后在浏览器中访问 `http://localhost:8000`。

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和响应式设计
- **JavaScript (ES6+)** - 游戏逻辑
- **HTML5 Canvas** - 贪吃蛇、打砖块、俄罗斯方块、太空射击、五子棋
- **Font Awesome** - 图标库
- **localStorage** - 游戏数据持久化

## ✨ 核心功能

- **响应式设计** - 完美适配电脑和移动设备
- **游戏分类** - 按益智、动作、策略、解谜分类浏览
- **搜索功能** - 快速找到喜欢的游戏
- **游戏加载系统** - 基于URL参数动态加载不同游戏
- **最高分记录** - 使用localStorage保存游戏数据
- **触摸支持** - 移动设备提供完整的触摸控制

## 🔧 扩展指南

### 添加新游戏

1. 在 `games/` 目录下创建新的游戏 HTML 文件
2. 在 `game.html` 的 `games` 对象中添加新游戏的详细信息
3. 在 `games.html` 中添加新游戏的卡片和链接
